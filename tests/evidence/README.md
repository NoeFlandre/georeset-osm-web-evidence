# Evidence Tests

Tests for URL fetching, readable text extraction, text quality metadata, and
sentence candidate generation.

- `test_page_text.py` and `test_web_text.py` cover page fetching and extraction metadata.
- `test_web_extraction.py` and `test_web_quality.py` cover parser behavior and quality scoring.
- `test_sentence_candidates.py`, `test_sample_sentences.py`, and `test_sample_sentence_candidates_script.py` cover sentence-level candidate preparation.
- `test_summary.py` covers polygon-level evidence summaries.
